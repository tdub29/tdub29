# Trevor White

Analytics engineer. I built and own the semantic layer behind Good360's reporting on $3.9B in annual donated product: one governed definition for each of 128 metrics, used by 20 departments in Power BI and by AI agents through MCP servers.

That work is private. The public repos here are side projects where the same methods show up: modeled warehouses, tested pipelines, and models that say how much they can actually predict.

## Start here

- **[baseball-analytics](https://github.com/tdub29/baseball-analytics)**: the transfer-portal scouting platform the University of San Diego coaching staff uses. Seven sources feed a SQLite and dbt warehouse, pitch-level models (Stuff+, xWhiff, xSLG, run value) score players, and Streamlit apps put the output in front of coaches.
- **[Kicker-Analysis](https://github.com/tdub29/Kicker-Analysis)**: NFL kicker fantasy forecasts. The finding is that weekly field goal attempts have negative out-of-sample skill, so the model forecasts touchdowns instead.
- **[boondock](https://github.com/tdub29/boondock)**: an offline map of where dispersed camping is legal on U.S. public land. A Python GIS pipeline bakes federal datasets into vector tiles, and the browser app runs with no backend.

Also: [CBB](https://github.com/tdub29/CBB) (March Madness advancement with seed-stratified models), [Baseball-Analysis](https://github.com/tdub29/Baseball-Analysis) (MLB run expectancy and win probability in R) and [WanBattedBall](https://github.com/tdub29/WanBattedBall) (batted-ball prediction for the Nick Wan challenge).

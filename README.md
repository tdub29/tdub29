## Public code

[Scout Skills](https://github.com/tdub29/scout-skills) is a local skill ranker and curated library for Claude Code, Codex and Cursor. It searches skill descriptions on disk so agents can find the instructions they need without loading the whole library.

[Orator](https://github.com/tdub29/speech-grading) turns recordings or transcripts into scored speech reports with highlighted delivery and word-choice feedback. It combines verbatim speech recognition with timing and acoustic analysis, and can suggest stronger wording where someone hesitates.

[Boondock](https://github.com/tdub29/boondock) is an offline browser map for dispersed camping on US public land. It combines geospatial data with the rules set by each land manager to answer where someone can camp.

[Sample dbt/DuckDB warehouse](https://github.com/tdub29/baseball-analytics#try-the-sample-dbt-warehouse) builds staging, intermediate and mart models from committed baseball fixtures, with model contracts and data tests. Run it locally without credentials.

## Sports modeling

[baseball-analytics](https://github.com/tdub29/baseball-analytics) brings together NCAA scouting tools used by University of San Diego coaches, a dbt and DuckDB warehouse, and MLB pitch and game models. It includes pitcher and hitter apps, run-expectancy forecasting, batter-pitcher matchups and Monte Carlo game simulation. The scouting apps and transfer portal board have been relied on by USD's back-to-back WCC regular season championship teams.

- [Kicker-Analysis](https://github.com/tdub29/Kicker-Analysis): weekly NFL kicker forecasts with season-forward backtests and baseline comparisons.
- [CBB](https://github.com/tdub29/CBB): March Madness models testing whether team statistics add information beyond tournament seed.
- [fantasy-football](https://github.com/tdub29/fantasy-football): a dynasty league hub and trade simulator using Sleeper feeds and KeepTradeCut values. Still a work in progress.
- [WanBattedBall](https://github.com/tdub29/WanBattedBall): a CatBoost batted-ball notebook from Nick Wan's Kaggle competition.
